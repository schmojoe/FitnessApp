# FitnessApp

A very basic iOS app for logging workout progress.

- [ ] ??/??/20?? : MVP core successfully launched on actual iPhone 14
- [ ] ??/??/20?? : MVP core demo produced (link to come)


## MVP Goals

- Create, edit, end, and delete workout programs
- Build a reusable weekly split with workout days and exercise set/rep-range goals
- Start a logged workout from a planned workout, or create a standalone strength or cardio session
- Record completed reps and weight for every strength set, with lbs/kg selection
- Log cardio activity, distance/unit, duration, and workout notes
- Review and delete past workout logs independently of their source program
